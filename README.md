# ЮаньЧек — карго или прямая доставка?

Приложение для Android и iPhone (веб-приложение PWA), которое считает, как выгоднее купить товар в Китае:
напрямую с маркетплейса или через карго. Разработчик: Glebov I.P., KZ.

## Что умеет
- **Прямая доставка**: цена в ¥ + НДС (ставка в настройках) + комиссия банка/эквайринг, доставка бесплатная.
- **Карго**: цена в ¥ без НДС + вес × тариф карго (в $, ¥ или ₸) + необязательная комиссия.
- Сравнение двух вариантов, подсветка выгодного и разница в ₸ и %.
- Цену можно вводить в ¥ (с НДС или без) или в HK$ из банка (в нём уже НДС и комиссия).
- **Автокурс**: курсы ¥, $, HK$ и € берутся с НБ РК при каждом запуске, поверх них действуют ваши поправки в %.
- **Обратный расчёт**: по реальной покупке (HK$, ₸, цена в ¥) определяет фактическую комиссию банка и курс HK$.
- **Таможня РК** для посылок физлиц: до 200 € и 31 кг платежей нет; сверх лимита — 15% от превышения
  стоимости или 2 € за кг превышения веса (берётся большая сумма). Лимиты и ставки редактируются.

## Как пользоваться
1. Введите цену товара в ¥ (выберите «без НДС» или «с НДС»), вес и цену карго за 1 кг.
2. Слева — прямая доставка, справа — карго; выгодный вариант подсвечен.
3. Один раз откалибруйте комиссию в «Обратном расчёте» по своей покупке.

## Источники правил
Таможенные нормы РК: сайт Комитета государственных доходов (kgd.gov.kz). Новый порядок для интернет-торговли
(5% + НДС) на момент выпуска версии отложен — следите за изменениями и правьте числа в настройках.
Расчёт ориентировочный и не является налоговой консультацией.

## Сборка APK
Загрузите проект в репозиторий GitHub — GitHub Actions соберёт APK (`.github/workflows/build.yml`) и
сохранит его в **Releases** под именем `YuanCheck-vX.Y.apk`. Версия задаётся в `app/build.gradle`
(`versionCode` +1 и `versionName`). История изменений — в `CHANGELOG.txt`.
Для отката скачайте нужную версию из Releases.

## iPhone (PWA)
Папка `pwa/` + `.github/workflows/pages.yml` публикуют тот же `index.html` как сайт на GitHub Pages
(Settings → Pages → Source: GitHub Actions). Откройте адрес сайта в **Safari** на iPhone →
«Поделиться» → «На экран Домой». Приложение работает на весь экран и без интернета.
Курс на iPhone берётся из открытого API (рыночный курс, а не НБ РК), поэтому один раз откалибруйте
комиссию в «Обратном расчёте».
